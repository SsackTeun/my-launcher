# 도구함 🧰

내가 만든 macOS 앱들을 카테고리별로 모아 두고, 각 앱은 따로 실행하는 런처입니다.

- 보기 방식: 아이콘 격자 ⊞ / 세로 목록 ☰ (보기 탭 줄 오른쪽 버튼). 탭 줄과 왼쪽 목록은 고정, 앱 목록만 스크롤
- 앱 영역에서 스크롤하면 강조가 앱을 한 칸씩 옮겨 감 (검색칸이 비어 있으면 Enter 로 강조된 앱 실행, 설정에 따라 끝에서 더 내리면 다음 카테고리로)
- 아이콘 클릭 → 실행 (이미 실행 중이면 앞으로 가져오기), 실행 중이면 초록 점
- 아래 버튼: **추가**(앱 고르기) · **빼기**(편집 모드, ⊖ 눌러 제거) · **카테고리**(새로 만들기·이름·순서·삭제) · ⚙︎ 설정
- 카테고리가 2개 이상이면 카테고리마다 제목 + 구분선으로 나뉨, 제목 우클릭으로 카테고리 메뉴
- 앱 아이콘을 끌어서 다른 카테고리나 다른 자리로 옮기기 (우클릭 → 카테고리 옮기기도 가능)
- Finder에서 .app 을 원하는 카테고리 위치에 끌어다 놓아도 추가됨
- 아이콘 우클릭 → 종료 · 순서 바꾸기 · Finder에서 보기 · 런처에서 빼기
- 설정(⌘,): 열 수, 카테고리당 최소 행 수, 아이콘 크기(24~128px, 작게/보통/크게/아주 크게)
- **위젯 모드**: 제목 막대 없는 둥근 반투명 카드로 바탕화면에 붙임 (다른 창 뒤 / 일반 / 항상 위), 끌어서 배치, 위치 고정, 빈 곳 우클릭으로 추가·빼기·카테고리·설정, 맨 위 손잡이를 잡고 끌어 옮기기, 맨 아래 손잡이로 목록 높이 조절(더블클릭하면 내용에 맞춤) (위젯일 때도 Dock·메뉴 막대에 표시 옵션, 기본 켜짐)
- **Dock 앱 가져오기**: Dock 에 고정된 앱을 "Dock" 카테고리로 한 번에 (다시 누르면 새로 생긴 것만)
- **켜져 있는 동안 Dock 가리기**: 도구함이 켜지면 Dock 자동 가리기를 켜고, 끄면 원래대로 (처음 한 번 System Events 제어 허용 필요)
- **검색**(맨 위 🔍, ⌘F): 도구함 앱 + 설치된 앱에서 찾기, Enter 로 첫 결과 실행, 결과 우클릭 → 도구함에 넣기
- **Finder 버튼**(맨 위 아이콘 묶음)
- **⧉ 떼어 내기**: 플레이어 · 가사 줄을 따로 떠 있는 작은 창으로 (다시 누르면 합치기, 위치 기억)
- **앱별 우클릭 메뉴**: Dock 처럼 열린 창 목록 · 새 창 · 그 앱의 메뉴 막대(앱 메뉴) · 가리기 · 종료 (손쉬운 사용 권한)
- **YouTube Music 미니 플레이어**: 도구함 안의 내장 브라우저로 YouTube Music 을 열어 곡 정보·앨범 사진·진행바·좋아요·셔플·반복·볼륨·재생 목록 (🪟 버튼으로 창 열기, 권한 필요 없음)
- **접기**: 맨 위 ⌃ 버튼으로 앱 목록 전체 접기(검색 줄 + 플레이어만), [모두 접기] 를 누르면 왼쪽에 카테고리 세로 목록 — 누른 카테고리 앱만 오른쪽에 보이고, 앱을 탭 위에 끌어다 놓으면 그 카테고리로, 왼쪽 목록 칸(앱이 한 화면에 들어가면 앱 영역도)에서 스크롤하면 카테고리 이동, 카테고리를 끌어서 순서 바꾸기
- **가사 + 번역**: 플레이어의 💬 버튼으로 가사 창. LRCLIB 의 시간 맞춤 가사가 있으면 노래에 맞춰 지금 줄 강조·자동 스크롤·줄 누르면 그 부분으로, 고른 언어로 줄마다 번역 (Apple 번역)
- **가사 줄**: 플레이어 아래에 지금 줄(+번역)·다음 줄, 노래에 맞춰 넘어감, ⌃/⌄ 펼치기·접기, A−/A+ 글자 크기, '전체 가사'로 전체 가사 창, 발음 옵션(일본어·중국어 한글 발음, 라틴 문자가 아닌 모든 가사 로마자)
- **창 정리**: 맨 위 버튼으로 열린 창 모두 닫기 · 모두 최소화 · 최소화한 창 모두 되살리기 · 앱 모두 종료(도구함·Finder 제외), 앱 골라서 종료(체크해서 한 번에, 응답 없으면 강제 종료)
- **데스크탑 탭**: 데스크탑(Space) 1·2·3… 마다 창이 열린 앱 보기 (Mission Control 처럼 모니터를 합쳐 이어지는 번호, 전체 화면 앱 따로, 지금 데스크탑 표시), 앱을 왼쪽 데스크탑 위로 끌어다 놓으면 그 데스크탑으로 (같은 모니터는 제목 막대 잡고 Ctrl+←/→ 로 넘기는 방식이라 잠깐 커서·화면이 움직임)
- **실행 중 탭**: 앱 목록 위 [전체 | 실행 중] — 켜져 있는 도구함 앱과 그 밖에 실행 중인 앱만 모아 보기, 마우스를 올리면 앱마다 ⓧ 종료 버튼 (⌥ 누르고 누르면 강제 종료, 설정에 따라 먼저 물어봄)
- **설정**: 창 위치 고정(일반 창·위젯), 글자 크기(기본 자동 — 화면·아이콘 크기에 맞춤, 직접 80~140%)
- **개발자 앱 탭**: GitHub 에서 받기 · 업데이트 표시 · 모두 업데이트
- **다시 시작**: 메뉴바 🧰 · 도구함 메뉴(⌘R) · 위젯 우클릭에서 도구함 다시 시작, 실행 중인 앱 우클릭 → 다시 시작
- 메뉴바 🧰 → 앱 목록, 모두 실행, 로그인 시 자동 실행

## 설치

- [Releases](https://github.com/SsackTeun/my-launcher/releases/latest) 에서 `Launcher.zip` 을 받아 압축을 풀고 Applications 폴더로 (macOS 26 이상, 애플 실리콘 · 인텔)
- 소스에서 빌드: `./build.sh` → `~/Applications/도구함.app`

## 개발자 앱

`apps.json` 에 적힌 앱들이 도구함의 **개발자 앱** 탭에 보여요. 누르면 각 저장소의 GitHub Releases 에서 받아 설치하고, 새 버전이 나오면 '업데이트' 표시가 떠요.
앱을 추가하려면 `apps.json` 에 한 줄 넣고, 그 저장소에 `release.sh` 처럼 zip 을 Releases 에 올리면 돼요.

## 새 버전 올리기

```bash
./release.sh 1.2
```

## Windows 판 (`windows/`)

같은 저장소의 `windows/` 폴더에 Tauri 로 만든 Windows 판이 있어요. (Windows 10/11)

- 시작 메뉴 앱을 모아 카테고리별로 실행 · 검색 · 왼쪽 목록 / 격자 · 목록 보기 · 끌어다 놓기 · 우클릭 메뉴
- 실행 중 탭 (앱마다 종료 · 메모리, Shift/Alt 누르고 누르면 강제 종료) · 개발자 앱 탭 · 위젯 모드(바탕화면에 붙이기 / 항상 위)
- **데스크탑 탭**: 가상 데스크톱마다 창이 열린 앱 (이름 · 지금 데스크탑 표시, 누르면 그 창으로). 다른 데스크탑으로 옮기기는 Windows 가 공개하지 않아 빠짐
- **앱별 우클릭 메뉴**: 열린 창 목록 · 새 창 · 모든 창 최소화/닫기 · 다시 시작 · 종료
- **창 정리**(맨 위 버튼): 모두 닫기 · 모두 최소화 · 최소화한 창 되살리기 · 앱 모두 종료 · 앱 골라서 종료 (안 꺼지면 강제 종료를 물어봄)
- **재생기 (YouTube Music · YouTube · Netflix)**: 맨 위 줄 · 떼어 낸 플레이어에 실제 아이콘 단추 — 누르기 열기 / 숨기기(백그라운드에서 계속 재생) / 앞으로, Shift+누르기 PIP, 오른쪽 클릭 메뉴. 한 번 로그인하면 세 창이 같이 씀
- **미니 플레이어**: ‹ › 로 재생기 넘기기, 새로 재생을 시작한 재생기로 넘어가고 나머지는 일시정지 (소리 없는 예고편 · 미리 보기는 빼고). 앨범 사진 · 진행바 · 셔플/반복/좋아요(YouTube Music) · 볼륨. 설정에서 '모든 앱'(Windows 미디어 컨트롤)으로도
- **크게 보기 (음악 창)**: 큰 앨범 + 탭 — 다음 트랙(눌러 재생 · 골라서 재생목록에 넣기) · 가사 · 앨범(지금 가수의 앨범 · 싱글) · 재생목록(내 계정 재생목록 재생 · 곡 빼기 · 지금 곡 넣기 · 새로 만들기 · 여러 개 지우기) · 랜덤 재생목록(가수 · 비중 · 곡 수/시간 · 인기곡 위주, 새로 만들기 또는 덧붙이기). YouTube Music 창 페이지 안에서 로그인 쿠키로 요청 (Mac 판과 같음)
- **가사 + 번역 + 발음**: LRCLIB 시간 맞춤 가사(지금 줄 강조 · 줄 누르면 이동), 가사 줄 / 전체 가사 창, 번역 · 일본어/중국어 한글 발음 · 로마자 (Google 번역 — 켤 때만 가사 글자를 보냄)
- **떼어 내기**: 플레이어 · 가사 줄을 항상 위 작은 창으로 (위치 기억)
- **청력 보호**: 귀에 들어가는 어림 크기(dB) · 오늘 들은 양, 크기 제한
- **자주 쓰는 앱 막대**: 화면 가장자리(왼 · 오른 · 위 · 아래) 막대, 끌어다 넣기 · 순서 · 빼기, '자리 비워 두기' 는 Windows 앱 바로 등록해 최대화한 창도 막대를 안 덮음
- **화면 끝 서랍**: 위젯을 왼쪽 · 오른쪽 끝에 붙이면 손잡이로 접기 · 펼치기, 창이 화면 밖으로 안 나가게
- **PIP (Mac 판과 같은 작은 창)**: YouTube · Netflix 창 오른쪽 아래 [PIP] → 제목 막대 없는 항상 위 작은 창에 영상만 (자막 보임), 영상 비율대로 · 끌어서 크기를 바꿔도 비율 유지(검은 여백 없음), 누르기 재생/멈춤 · 두 번 누르기 원래 창 · 끌어 옮기기 · 휠 볼륨, 자리 기억. 창을 닫으면 영상 멈추고 숨기기 (다시 열면 그대로). Netflix 는 도구함 창 안에서 보이게 하드웨어 보호 재생 대신 소프트웨어 보호 재생(HD)
- **YouTube Music 휴대폰 크기 창** (아이콘 오른쪽 클릭)
- **작업 표시줄**: 고정된 앱 가져오기, 도구함이 켜져 있는 동안 자동 숨기기
- **트레이(알림 영역) 🧰**: 앱 목록 · 모두 실행 · 로그인 시 자동 실행 · 다시 시작 (Ctrl+R), 창을 닫으면 트레이로
- **설정**(⚙ · Ctrl+,): 테마(기본 · 밝게 · 곰) · 배경 그림 · 글자 크기 · 아이콘 크기 등
- Mac 판에만 있는 것: 소리 보정 · 이퀄라이저 · 정밀 EQ (Windows 는 시스템 소리를 바꾸려면 별도 드라이버가 필요), 메일
- 받기: [Releases](https://github.com/SsackTeun/my-launcher/releases) 의 `win-v…` 에서 `Launcher-Windows-Setup.exe`
- 빌드는 GitHub Actions(Windows)가 해요: `windows/` 가 바뀌면 빌드, `win-v0.2.0` 같은 태그를 올리면 Releases 에 올라감
- 로컬에서: `cd windows && npm ci && npx tauri dev` (Windows PC 에서)
