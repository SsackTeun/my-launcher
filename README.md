# 도구함 🧰

내가 만든 macOS 앱들을 한곳에 모아 두고, 각 앱은 따로 실행하는 런처입니다.

- 아이콘 클릭 → 실행 (이미 실행 중이면 앞으로 가져오기), 실행 중이면 초록 점
- 아래 버튼: **추가**(앱 고르기) · **빼기**(편집 모드, ⊖ 눌러 제거) · ⚙︎ 설정
- Finder에서 .app 을 창에 끌어다 놓아도 추가됨
- 아이콘 우클릭 → 종료 · 순서 바꾸기 · Finder에서 보기 · 런처에서 빼기
- 설정(⌘,): 열 × 행 배치, 아이콘 크기(24~128px, 작게/보통/크게/아주 크게)
- 메뉴바 🧰 → 앱 목록, 모두 실행, 로그인 시 자동 실행

## 설치

```bash
./build.sh
```
