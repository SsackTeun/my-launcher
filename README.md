# 도구함 🧰

내가 만든 macOS 앱들을 카테고리별로 모아 두고, 각 앱은 따로 실행하는 런처입니다.

- 보기 방식: 아이콘 격자 ⊞ / 세로 목록 ☰ (보기 탭 줄 오른쪽 버튼)
- 앱 영역에서 스크롤하면 강조가 앱을 한 칸씩 옮겨 감 (검색칸이 비어 있으면 Enter 로 강조된 앱 실행, 설정에 따라 끝에서 더 내리면 다음 카테고리로)
- 아이콘 클릭 → 실행 (이미 실행 중이면 앞으로 가져오기), 실행 중이면 초록 점
- 아래 버튼: **추가**(앱 고르기) · **빼기**(편집 모드, ⊖ 눌러 제거) · **카테고리**(새로 만들기·이름·순서·삭제) · ⚙︎ 설정
- 카테고리가 2개 이상이면 카테고리마다 제목 + 구분선으로 나뉨, 제목 우클릭으로 카테고리 메뉴
- 앱 아이콘을 끌어서 다른 카테고리나 다른 자리로 옮기기 (우클릭 → 카테고리 옮기기도 가능)
- Finder에서 .app 을 원하는 카테고리 위치에 끌어다 놓아도 추가됨
- 아이콘 우클릭 → 종료 · 순서 바꾸기 · Finder에서 보기 · 런처에서 빼기
- 설정(⌘,): 열 수, 카테고리당 최소 행 수, 아이콘 크기(24~128px, 작게/보통/크게/아주 크게)
- **위젯 모드**: 제목 막대 없는 둥근 반투명 카드로 바탕화면에 붙임 (다른 창 뒤 / 일반 / 항상 위), 끌어서 배치, 위치 고정, 빈 곳 우클릭으로 추가·빼기·카테고리·설정, 맨 위 손잡이를 잡고 끌어 옮기기, 맨 아래 손잡이로 목록 높이 조절(더블클릭하면 내용에 맞춤)
- **Dock 앱 가져오기**: Dock 에 고정된 앱을 "Dock" 카테고리로 한 번에 (다시 누르면 새로 생긴 것만)
- **켜져 있는 동안 Dock 가리기**: 도구함이 켜지면 Dock 자동 가리기를 켜고, 끄면 원래대로 (처음 한 번 System Events 제어 허용 필요)
- **검색**(맨 위 🔍, ⌘F): 도구함 앱 + 설치된 앱에서 찾기, Enter 로 첫 결과 실행, 결과 우클릭 → 도구함에 넣기
- **Finder 버튼**(맨 위)
- **앱별 우클릭 메뉴**: Dock 처럼 열린 창 목록 · 새 창 · 그 앱의 메뉴 막대(앱 메뉴) · 가리기 · 종료 (손쉬운 사용 권한)
- **YouTube Music 미니 플레이어**: 도구함 안의 내장 브라우저로 YouTube Music 을 열어 곡 정보·앨범 사진·진행바·좋아요·셔플·반복·볼륨·재생 목록 (🪟 버튼으로 창 열기, 권한 필요 없음)
- **접기**: 맨 위 ⌃ 버튼으로 앱 목록 전체 접기(검색 줄 + 플레이어만), [모두 접기] 를 누르면 왼쪽에 카테고리 세로 목록 — 누른 카테고리 앱만 오른쪽에 보이고, 앱을 탭 위에 끌어다 놓으면 그 카테고리로, 왼쪽 목록 칸(앱이 한 화면에 들어가면 앱 영역도)에서 스크롤하면 카테고리 이동, 카테고리를 끌어서 순서 바꾸기
- **가사 + 번역**: 플레이어의 💬 버튼으로 가사 창. LRCLIB 의 시간 맞춤 가사가 있으면 노래에 맞춰 지금 줄 강조·자동 스크롤·줄 누르면 그 부분으로, 고른 언어로 줄마다 번역 (Apple 번역)
- **가사 줄**: 플레이어 아래에 지금 줄(+번역)·다음 줄, 노래에 맞춰 넘어감, ⌃/⌄ 펼치기·접기, A−/A+ 글자 크기, '전체 가사'로 전체 가사 창, 발음 옵션(일본어·중국어 한글 발음, 라틴 문자가 아닌 모든 가사 로마자)
- **창 정리**: 맨 위 버튼으로 열린 창 모두 닫기 · 모두 최소화 · 앱 모두 종료(도구함·Finder 제외), 앱 골라서 종료(체크해서 한 번에, 응답 없으면 강제 종료)
- **실행 중 탭**: 앱 목록 위 [전체 | 실행 중] — 켜져 있는 도구함 앱과 그 밖에 실행 중인 앱만 모아 보기
- **설정**: 창 위치 고정(일반 창·위젯), 글자 크기(기본 자동 — 화면·아이콘 크기에 맞춤, 직접 80~140%)
- **개발자 앱 탭**: GitHub 에서 받기 · 업데이트 표시 · 모두 업데이트
- 메뉴바 🧰 → 앱 목록, 모두 실행, 로그인 시 자동 실행

## 설치

- [Releases](https://github.com/SsackTeun/my-launcher/releases/latest) 에서 `Launcher.zip` 을 받아 압축을 풀고 Applications 폴더로 (macOS 26 이상, 애플 실리콘 · 인텔)
- 소스에서 빌드: `./build.sh` → `~/Applications/도구함.app`

## 개발자 앱

`apps.json` 에 적힌 앱들이 도구함의 **개발자 앱** 탭에 보여요. 누르면 각 저장소의 GitHub Releases 에서 받아 설치하고, 새 버전이 나오면 '업데이트' 표시가 떠요.
앱을 추가하려면 `apps.json` 에 한 줄 넣고, 그 저장소에 `release.sh` 처럼 zip 을 Releases 에 올리면 돼요.

## 새 버전 올리기

```bash
./release.sh 1.2
```
